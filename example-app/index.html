Typical update flow

  1. Check whether the update server has a newer web bundle for your channel.
  2. Download the bundle when an update is available.
  3. Apply or queue the bundle, then reload so the WebView serves the new files.
  4. Call notifyAppReady so the plugin knows the current bundle is healthy (done automatically on launch unless disabled for a test).
